# Just Me Media Homebrew tap

```bash
brew trust just-me-media/tap   # only needed on Homebrew versions that ask
brew install --cask just-me-media/tap/roundtable
```

## Casks

| Cask | App |
|---|---|
| `roundtable` | [Roundtable](https://github.com/Just-Me-Media/FreeLLMAPI-Roundtable) — several AI models in one shared, role-based conversation |

The cask is generated from the notarized universal DMG by `npm run cask` in the app repo, so the checksum always matches the published release.
